Aplikasi WebGL2 interaktif 2D untuk menguji dan memvisualisasikan matriks transformasi geometri linear (Translasi, Rotasi, dan Skala) serta efek hierarki *transform order*.

## 2. Cara Menjalankan Aplikasi
Aplikasi ini dibangun menggunakan ES Module JavaScript murni (type="module"), sehingga membutuhkan lokal web server atau fitur Live Server agar berkas modul dapat dimuat tanpa terhalang kebijakan CORS peramban (browser).
Langkah-langkah:
Pastikan seluruh berkas berikut berada dalam satu direktori/folder yang sama:
index.html
style.css
main.js
math3d.js
README.md
Jalankan lokal web server:
Menggunakan VS Code: Buka folder di Visual Studio Code, klik kanan pada index.html dan pilih Open with Live Server.
Menggunakan Python (Opsional): Buka terminal di folder proyek dan jalankan command python -m http.server 8000, lalu buka http://localhost:8000 di peramban.
Menggunakan Node.js/npx (Opsional): Jalankan command npx serve . pada terminal.
